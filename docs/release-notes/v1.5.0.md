# Analytics Copilot v1.5.0: notas de versión

**Para**: el agente que mantiene antonioluisperez.com
**Objetivo**: versión pequeña. No hay herramienta nueva, el número sigue siendo 10 y los enlaces no cambian.

---

## Resumen en una línea

La pantalla de Inicio tiene un enlace "Proponer una mejora" que abre GitHub con dos formularios cortos: uno para ideas y otro para avisar de fallos.

## Qué cambia en la página

| Dónde | Cambio |
|---|---|
| Versión, si se muestra | 1.5.0 |
| Pie o sección de contacto | Opcional: un enlace "¿Echas algo en falta? Propón una mejora" a https://github.com/antonioluisperez/analytics-copilot/issues/new/choose |

### Frase suelta, por si se usa

> ¿Echas algo en falta al hacer QA? Propón una mejora o avisa de un fallo desde la propia extensión.

## Contexto, por si se menciona en un changelog

- **Proponer una mejora.** En el pie de Inicio, junto al nombre del autor. Abre la página de GitHub para elegir entre "Proponer una mejora" y "Avisar de un fallo".
- **Formularios.** El de ideas pregunta qué te gustaría que hiciera y cómo lo compruebas hoy a mano; el de fallos, qué pasa, los pasos, la web y la versión. Así las propuestas llegan con lo necesario para valorarlas.
- La extensión no envía nada: el enlace solo abre una pestaña de GitHub. Hace falta una cuenta de GitHub para publicar el issue.

Sin permisos nuevos.

## Origen

Idea de Antonio (29 de octubre de 2026): que las unas 140 personas que usan la extensión, casi todas analistas web, puedan proponer mejoras sin tener que buscar el repositorio. Hasta ahora no había ningún issue abierto ni otra forma visible de pedir nada. Quien usa la extensión nota un enlace nuevo en el pie de Inicio.
